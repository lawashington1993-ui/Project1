Data management console for the emergency services information system.

Choose an action, complete the fields, and submit. Changes are sent to the REST API and written to data.json.

Ready. Submit a form to see the API response.

The API returns 201 Created for additions, 200 OK for updates, 204 No Content for deletions, and 404 Not Found when a record does not exist.
